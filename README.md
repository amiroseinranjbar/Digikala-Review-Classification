# 🛍️ Digikala — Persian Customer Reviews Analysis

### Turning Customer Feedback into Meaningful Insights

Digikala Reviews Analysis is a Natural Language Processing (NLP) project focused on exploring and understanding Persian customer reviews from one of Iran's largest e-commerce platforms.

Every customer review tells a story — an experience with a product, an opinion about its quality, or an expression of satisfaction or dissatisfaction. This project explores how these opinions can be understood and transformed into meaningful insights using Natural Language Processing and Machine Learning.

### 🎯 Project Objectives

The project focuses on two key dimensions of customer feedback:

- **Customer Recommendation Analysis:** Identifying whether customers recommend a product, express no clear opinion, or do not recommend it.
- **Customer Rating Analysis:** Understanding customer satisfaction through three rating categories: Low, Medium, and High.

### 📊 Dataset Overview

The project is based on a large-scale Persian customer review dataset collected from Digikala.

| Attribute | Description |
|---|---:|
| Total Reviews | 6,156,289 |
| Number of Features | 15 |
| Dataset Size | ~1.22 GB |
| Language | Persian (Farsi) |
| Platform | Digikala |

The dataset contains over **6.15 million customer reviews**, providing a rich source of real-world feedback for exploring customer opinions, product satisfaction, and recommendation patterns.

### 💡 Why This Project?

With millions of customer reviews, valuable information is hidden within large volumes of unstructured Persian text. Analyzing this feedback can help reveal customer preferences, identify common concerns, and provide a better understanding of product experiences.

### 🔍 Project Scope

This project brings together Persian NLP, text classification, and machine learning to explore customer opinions at scale and turn raw textual feedback into structured, interpretable information.

**The ultimate goal is to better understand what customers think, what they value, and what influences their product experiences.**
